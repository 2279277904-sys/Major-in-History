# Major in History

面向历史学学习、史料阅读、研究设计和学术写作的 Codex Skills 集合。

## 当前 Skills

| Skill | 用途 |
|---|---|
| `historical-research-design` | 把兴趣问题转成可研究的历史学问题和研究计划 |
| `historical-source-criticism` | 对史料进行外部批判、内部批判和证据分级 |
| `primary-source-analysis` | 分析一手史料，区分原文、释文、转录、译文和解释 |
| `historiography-literature-review` | 整理学术史、研究现状、争论和文献综述 |
| `historical-research-notes` | 建立可追溯的读书卡片、引文、页码和论证笔记 |

这些 Skills 是学习和研究辅助工具，不替代历史学者的判断，也不把未经核验的推断写成史实。
