# Historiography and Literature Review

## Workflow

1. Define the field, time span, language range and inclusion criteria.
2. Separate primary sources from secondary scholarship and reference works.
3. For each work, record question, period, sources, method, thesis, evidence, contribution, limits and response to earlier scholarship.
4. Group works by debate or problem, not only by publication date.
5. Identify changes in concepts, periodization, archive use, scale, methodology and explanatory models.
6. Distinguish consensus, active dispute, minority position and untested assumption.
7. Write the review as an argument about the field's development, not as an annotated bibliography dump.

## Required evidence discipline

- Never infer a scholar's position from a title or abstract alone when the full text is available.
- Quote or cite the exact page for a strong claim.
- Separate what the author says from the reviewer's characterization.
- Do not call something a “research gap” merely because the Agent has not found it.
- Search variant names, translated titles, traditional/simplified forms and older terminology.
- Mark missing full texts, uncertain publication data and inaccessible citations.
