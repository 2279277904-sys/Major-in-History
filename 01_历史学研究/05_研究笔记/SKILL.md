# Historical Research Notes

## Note types

- `bibliographic_card`：完整书目信息和版本信息。
- `source_card`：一手史料来源、载体、年代、出处和史料性质。
- `quotation_card`：原文、页码、上下文、转录/译文和用途。
- `argument_card`：作者问题、论点、证据、方法和局限。
- `concept_card`：术语原文、历史语境、不同定义和使用范围。
- `research_question`：问题、证据、反证和下一步。

## Mandatory fields

Every note should include:

```text
note_id:
source_title:
author_or_creator:
edition_or_version:
publication_or_creation_date:
page_or_item:
source_url_or_path:
access_date:
original_text:
normalized_text:
translation:
my_note:
evidence_status:
related_questions:
tags:
```

## Rules

- Never record a quotation without a page, folio, item number or stable location.
- Keep quotation and paraphrase visibly separate.
- Keep the user's interpretation separate from the author's words.
- Preserve original and normalized forms separately for names, places, institutions and technical terms.
- Record uncertainty at the moment it is encountered; do not rely on memory later.
- When two editions differ, create separate readings and note the difference.
- A bibliography entry is not evidence that the work supports a particular claim.

## Research-log habit

End each reading session with: pages covered, notes created, claims needing verification, unresolved terms, missing sources and next action.
